# Sales Data Analysis Dashboard

## 📊 Project Overview

This project analyzes a structured retail sales dataset using Google Sheets and core Excel-style data analysis techniques.

The project focuses on formulas, sorting, filtering, PivotTables, KPIs, and business insights to understand sales performance across products, categories, regions, and salespersons.

## 🎯 Objectives

- Analyze sales data using spreadsheet formulas
- Calculate important business KPIs
- Analyze sales by region and category
- Compare salesperson performance
- Analyze product-wise sales and quantity
- Use sorting and filtering for data exploration
- Create PivotTables for business analysis
- Generate meaningful business insights

## 🛠️ Tools Used

- Google Sheets
- Spreadsheet Formulas
- PivotTables
- Sorting & Filtering
